## 从购买到朋友进服，一共七步

以下路径来自雨云论坛的官方教程。教程做于 2022 年，翼龙面板的按钮文案可能已经调整，走向大致一致，具体以当前面板为准。

1. 登录雨云，点顶部的 `游戏云`，再点 `购买游戏云`。
2. 服务端类型选 `Minecraft 基岩版`，弹出菜单里选 `官方基岩版`。这一步决定后面拿到的是一台已经装好官方服务端的实例，不需要自己上传开服包。
3. 选机型配置，点 `立即购买`。付款完成，服务器就已经创建好了。
4. 回到游戏云主页，能看到刚买的实例。进实例页，面板账号和密码就显示在那里。
5. 点 `进入翼龙面板`，用那组账号密码登录。
6. 登录后单击服务器标签进入管理页，直接点开机。等实例开始显示运行时间，就表示开服成功。
7. 打开本地游戏客户端，进 `服务器` 页面，划到最底部点 `添加服务器`。把面板上显示的地址按冒号拆开填。

第七步是新手最高频的卡点，单独说。

## 朋友连不上，先查这三件事

**地址必须拆成两段填。** 面板给的地址是 `主机名:端口` 的形式。冒号前面那段填进 `服务器地址` 栏，冒号后面那段填进 `端口` 栏。很多人把整串地址粘进地址栏，或者把两段填反，客户端只会报连不上，不会提示你填错了。这个地址可以直接发给朋友，他们照同样的方式添加就行。

**基岩版走的是 19132 端口的 UDP 协议。** 这跟 Java 版的 TCP 不是一回事，防火墙或安全组里要放行的是 `19132/udp`，放行成 tcp 等于没放。朋友进不来，第一嫌疑永远是端口和协议，而不是版本对不上。如果你在面板里改过服务端端口，放行的端口号要跟着改。

**换存档要先把 `worlds` 清空。** 面板里点 `文件`，往下翻找到 `worlds` 文件夹，把里面原有文件全部删干净，再上传自己的存档，然后重启服务器。留着旧文件直接覆盖，容易出现新旧世界混在一起、地形接缝错位的情况。

还有一件容易被忽略的事：如果你为了省事关掉了正版验证，也就是把 `server.properties` 里的 `online-mode` 从 `true` 改成 `false`，所有人进服后都会显示默认皮肤。想要正常显示皮肤，得再装一个 SkinsRestorer 这类皮肤插件。面板服能不能改配置文件、能不能装插件，取决于你选的套餐形态，下单前问一句客服最稳。

## 什么时候面板服就不够用了

雨云官方那篇教程自己写得很坦白：这份教程是给面板服准备的，方便朋友之间联机；想开公共服务器，建议买 VPS。它还加了一句自我限定，说是完全新手向，照做一定能开服，但**只是能开服**。

这句话划出了能力边界。面板服卖的是“开起来”这件事，预设服务端、可视化文件管理、一键开机，代价是你对服务端本身的控制权有限。一旦你想要 Bukkit/Spigot 那套插件生态，或者想让 Java 版和基岩版玩家进同一张地图，就超出面板服的默认范围了。

互通这件事的技术门槛在协议层。Java 版用 TCP 加 NBT 数据格式，基岩版依赖 UDP/RakNet，两边不是同一种语言，需要翻译层。主流做法是用 Geyser 做协议翻译，把基岩版数据包实时转成 Java 服务端能识别的格式，再用 Floodgate 完成基岩版玩家和 Java 账号体系的映射。Geyser 的落地形态就是一个插件包，需要放进服务端的 `plugins` 目录，还得改它的 `config.yml`。

所以真正的问题是：你选的这档套餐允不允许上传自定义服务端、给不给 `plugins` 目录的写权限。这一点雨云没有在公开资料里写明，下单前必须确认，别默认它能做。
